# Code Study

This project contains a prototype module for generating fill-in-the-blank questions from Python code snippets. It parses a snippet with Python's `ast` module and prepares question objects similar to interactive coding platforms.

## Usage

Run the question generator with a Python snippet:

```bash
python question_generator.py "result = 5 + 3"
```

This will output a single fill-in-the-blank question.
